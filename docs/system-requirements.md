
# System Requirements

## Project
GoCar Car Rental Booking System

## Reference System
GoCar Malaysia

## Purpose
An academic car rental booking application based on publicly observable
booking features of GoCar Malaysia.

## Requirements Status
To be finalized by the team before generating Codebase A and Codebase B.

## Planned Features
- User registration and login
- Browse available cars
- View car details and rental prices
- Select rental options
- Create a booking
- Simulated payment status
- View booking history
- Basic administrator management of cars and bookings

## Notes
This is an educational implementation, not GoCar's actual internal software.
The final agreed requirements must be identical for both AI-generated codebases.
