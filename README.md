
# GoCar Car Rental Booking System

## Project Overview
An academic Car Rental Booking System based on publicly observable booking
features of GoCar Malaysia. This project is developed for the
CSEB5213 Software Evolution & Maintenance assignment.

This is an educational implementation and is not GoCar's actual internal software.

## Project Objectives
- Develop two codebases using generative AI.
- Compare their software quality.
- Identify and refactor critical code smells.
- Demonstrate refactoring results.
- Design a Software Maintenance Life Cycle (SMLC) model.
